Reasonance

Map what you think, and why. Then see where people really agree.

  • Every statement and every inference is a post. Arrows run from a claim to the reasons for and against it.
  • Argue about the reasoning itself, not just the facts: an arrow can be supported or contended too.
  • Say how much you agree and how sure you are. Your views stay private unless you share them.
  • Each statement is posted once, so everyone builds on the same map instead of talking past each other.
